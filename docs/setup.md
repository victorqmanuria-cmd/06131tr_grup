# Setup — Instal·lació i configuració

## Requisits previs

- Tenir accés al repositori de GitHub.
- Disposar de Git instal·lat si es vol treballar amb una còpia local del projecte.

## Obtenir el projecte

El repositori del projecte és:

https://github.com/victorqmanuria-cmd/06131tr_grup

Per clonar el repositori al teu ordinador, executa:

```bash
git clone https://github.com/victorqmanuria-cmd/06131tr_grup.git
cd 06131tr_grup
```

## Estructura del projecte

- `src/`: codi font de l'aplicació.
- `tests/`: proves del projecte.
- `docs/`: documentació del projecte.
- `README.md`: presentació general del repositori.

## Instal·lació i execució

Les instruccions específiques d'instal·lació i execució s'actualitzaran quan estiguin definides les tecnologies i els requisits de l'aplicació.

# Contributing Guidelines — Guia de contribució

## Objectiu

Aquesta guia defineix el procediment que han de seguir els membres de l'equip per col·laborar en el projecte.

## Flux de treball

1. Revisar la tasca que s'ha de realitzar.
2. Crear una branca específica per a la tasca.
3. Fer els canvis necessaris a la branca pròpia.
4. Descriure els canvis amb missatges de commit clars.
5. Crear una Pull Request cap a la branca `develop`.
6. Demanar la revisió d'un altre membre de l'equip abans de fusionar els canvis.

## Convenció de noms de branques

- `feature/nom-funcionalitat`: per desenvolupar funcionalitats o tasques noves.
- `bugfix/descripcio-error`: per corregir errors.
- `docs/descripcio-documentacio`: per modificar la documentació.

## Bones pràctiques

- Mantenir els canvis relacionats amb una mateixa tasca.
- Escriure missatges de commit descriptius.
- Actualitzar la documentació quan s'afegeixin funcionalitats.
- No pujar contrasenyes, dades sensibles ni fitxers innecessaris al repositori.
- Comprovar els canvis abans de crear una Pull Request.

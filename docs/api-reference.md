# API Reference — Referència de l'API

## Introducció

Aquest document està destinat a descriure les interfícies i els endpoints de l'API del projecte, si escau.

## Endpoints

Els endpoints es documentaran quan estiguin definits i implementats en el projecte.

Per a cada endpoint s'indicarà:

- **Mètode HTTP:** GET, POST, PUT o DELETE, segons correspongui.
- **Ruta:** adreça de l'endpoint.
- **Paràmetres:** dades necessàries per fer la petició.
- **Resposta:** dades retornades per l'API.
- **Errors possibles:** codis i missatges d'error.

## Actualització

La documentació s'haurà de mantenir actualitzada quan s'afegeixin o es modifiquin endpoints.

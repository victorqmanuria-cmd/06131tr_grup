# Architecture — Arquitectura del projecte

## Descripció general

Aquest repositori conté el projecte de grup del mòdul 613 de desenvolupament d'aplicacions.

## Estructura del projecte

El repositori s'organitza en els directoris i fitxers següents:

- `src/`: conté el codi font de l'aplicació.
- `tests/`: destinat a les proves del projecte.
- `docs/`: conté la documentació.
- `README.md`: presenta el projecte.
- `.gitignore`: defineix els fitxers que Git ha d'ignorar.

## Organització del treball

El projecte utilitza diferents branques per organitzar el desenvolupament:

- `main`: branca principal del repositori.
- `develop`: branca d'integració dels canvis.
- `feature/*`: branques per treballar en funcionalitats o tasques específiques.

## Evolució de l'arquitectura

La descripció dels components interns i de les relacions entre ells s'ampliarà a mesura que s'implementin les funcionalitats del projecte.
